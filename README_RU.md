# ПОСЛЕДНИЙ МИР (LastWorld) — Forge 1.20.1

Это исходный проект мода для Minecraft Java Edition 1.20.1 / Forge 47.2.0 / Java 17.

## Что включено
- Моб «Наблюдатель» с использованием приложенной текстуры.
- Появления рядом с игроком по серверному таймеру, преимущественно ночью.
- ИИ наблюдения и преследования: моб иногда смотрит на игрока, а затем может исчезать.
- Сюжетные события и счётчик присутствия в сохранении игрока.
- Редкие клиентские затемнения и звуковые сигналы.
- Записки в виде предмета и стартовая сюжетная запись в чате.
- Основа измерения «Пустота памяти» как datapack-ресурсы.

## Сборка
1. Установи Java 17 (JDK).
2. Установи Gradle или используй wrapper, созданный ForgeGradle при импорте проекта в IntelliJ IDEA.
3. Открой папку проекта в IntelliJ IDEA как Gradle-проект.
4. Выполни `gradle build`.
5. Готовый JAR будет в `build/libs/lastworld-1.0.0.jar`.
6. Положи JAR в папку `mods` своего профиля Forge 1.20.1.

## Важно
Это полный исходный проект первой игровой версии, но он не был собран в этой среде: здесь нет доступа к скачиванию ForgeGradle/Minecraft dependencies. Поэтому я не могу честно утверждать, что JAR уже скомпилирован и протестирован. Если Gradle сообщит об ошибке совместимости, смотри её вывод и проверь, что используется JDK 17.

Текстура из исходного сообщения помещена в `assets/lastworld/textures/entity/observer.png`. Если текстура визуально не подходит к форме модели, потребуется поправить UV-развёртку в `ObserverModel.java` или модель в Blockbench.


## Структура проекта
Проект оформлен по шаблону ForgeGradle из референсной папки SculkTitan: версии находятся в `gradle.properties`, а сборка настроена через `build.gradle`.

Для сборки требуется Java 17 и Gradle 8.8:
`gradle build --no-daemon`

В репозитории настроен GitHub Actions workflow `.github/workflows/build.yml`; после push он попробует собрать JAR и прикрепить его как Artifact при успешной сборке.
